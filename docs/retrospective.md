# Retrospectiva final

## Qué aprendí
Durante este proyecto conecté todo lo aprendido en las fases anteriores:
React con TypeScript para el frontend, Express para el backend, Tailwind
para los estilos y MongoDB para la persistencia de datos.

## Tecnologías utilizadas
- **Frontend:** React + TypeScript + Tailwind CSS + Vite
- **Backend:** Node.js + Express + TypeScript
- **Base de datos:** MongoDB Atlas con Mongoose
- **Autenticación:** Firebase Auth
- **Despliegue:** Vercel (frontend) + Railway (backend)

## Funcionalidades implementadas
- Autenticación con Firebase (registro e inicio de sesión)
- Gastos vinculados a cada usuario
- Campos fiscales: IVA (0%, 4%, 10%, 21%) e IRPF (0%, 7%, 15%, 19%, 21%)
- Resumen fiscal automático
- Grupos familiares/empresa con código de invitación
- Persistencia de datos con MongoDB

## Principales problemas
- Permisos de Windows al crear carpetas en la unidad X:
- Configurar CORS entre frontend y backend en producción
- Autorizar el dominio de Vercel en Firebase Auth
- Gestionar variables de entorno entre Vercel y Railway

## Cómo usé la IA
Usé IA para guiarme en la estructura del proyecto, resolver errores de
TypeScript, configurar Firebase Auth, integrar MongoDB y gestionar
el despliegue en Vercel y Railway.

## Reflexión final
Desarrollar una app fullstack completa orientada a PYMEs y autónomos
me ha dado una visión global del desarrollo web profesional. La combinación
de TypeScript en frontend y backend, Firebase para la autenticación y
MongoDB para la persistencia reduce drásticamente los errores en producción
y hace la app escalable para futuros requisitos.
